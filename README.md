# RaST – Handmade Pottery E-commerce Platform

RaST is a Persian e-commerce platform for handmade pottery products, developed using PHP and MySQL.

## Features

- User registration and authentication
- Product browsing and product details
- Shopping cart management
- Favorites management
- Checkout and order processing
- Admin dashboard
- Product and order management
- Persian-language interface

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Setup

1. Clone or download this repository.
2. Create a MySQL database named `shop_db`.
3. Import `database/schema.sql` using phpMyAdmin.
4. Create `config/database.local.php` with your local database credentials.
5. Configure your local PHP and MySQL environment.
6. Run the project through your local server.

## Note

This project was developed as a local PHP/MySQL application and is not currently deployed online.
